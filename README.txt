OTIPM Interventionsplaner – GitHub Pages

1. Neues öffentliches GitHub-Repository anlegen (z. B. OTIPM-Interventionsplaner).
2. index.html und .nojekyll aus diesem ZIP entpacken und im Repository hochladen.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Nach Veröffentlichung die HTTPS-Adresse aus Settings > Pages kopieren und in Microsoft Teams teilen.

Bitte auf iPad (Safari) und Android (Chrome) prüfen. Keine personenbezogenen Patientendaten eingeben. Die Browser-Zwischenspeicherung bleibt auf dem jeweiligen Gerät und kann gelöscht werden.
